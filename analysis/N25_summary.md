# N25: the direct benchmark under a finish-to-start reading of reorder (l1-n25-fts-1)

Generated by `code/scripts/n25_finish_to_start.py` on core 14 (one thread): deterministic dispatcher replays (n11_decision_time.gen_price, no solver, no time budget), no model call, no GPU. Post hoc sensitivity analysis. Frozen design: `results/n25_finish_to_start/design.md` (sha256 a7ad31fb643899e46daaae635e2d0ceb27a089e66d60ba17735eed830078f32b), addendum `results/n25_finish_to_start/addendum.md`. Reused: n24 (imported), and through it n20/n16/n18/n13 loaded from source with the core allowance set to core 14 in memory (files untouched): n20.build's records, n13.costly_of, the published flags, n16.sp_flag, n24.headline (n20.tally, n13.score), n2.Boot (seed 20261026, 20000 replicates, 60 instance clusters).

Reading S is the published dispatcher (start-after-start: a successor is eligible once its predecessors have started). Reading F is the same dispatcher with the eligibility test replaced in memory: a successor is eligible once every predecessor has completed (end <= now), and the trades of the successors of an order that completes join the sweep at that instant. Everything else is unchanged (ATC, seed 0, frozen set 'fix', batch rules, a freeze wins over a precedence edge, apply.py, the guard's stages, the logged bounds and floor). K = known board at t_d, FI = full-information board at t_d, realised = the whole-window run from t_d. bh = business hours.
